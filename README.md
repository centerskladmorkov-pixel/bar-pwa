# Морковь Фрут · БАР — приложение (PWA)

Открыть: https://centerskladmorkov-pixel.github.io/bar-pwa/

Это собранный интерфейс приложения «Морковь Фрут · БАР» для установки на телефон (иконка на экране, запуск
без браузера, быстрое открытие). Данные и вход — на сервере приложения (Google Apps Script), как и по обычной ссылке:
здесь нет серверного кода, ключей, паролей и данных.

Файлы не правятся вручную — их пересобирает `tools/build_pwa.js` проекта.

**Установка на Android:** открыть адрес в Chrome → меню «⋮» → «Установить приложение» (или «Добавить на гл. экран»).
**На iPhone:** открыть в Safari → «Поделиться» → «На экран „Домой“».
